# Parallel Algorithms Visualizer

Програмний комплекс для візуалізації паралельних алгоритмів та анімації передачі повідомлень між процесорами.

Цей проєкт є дипломною роботою, мета якої — створити інтерактивний інструмент для вивчення та аналізу роботи паралельних алгоритмів на різних топологіях обчислювальних мереж. Програма дозволяє обирати задачу, метод її розв'язання та топологію, після чого візуалізує процес обміну повідомленнями у вигляді анімації, а також розраховує теоретичний час виконання за математичною моделлю.

## 🚀 Ключові можливості

- **Вибір параметрів:** Інтуїтивно зрозумілий інтерфейс для вибору задачі, методу, топології, кількості процесорів та інших параметрів.
- **Топології:** Підтримка 6 топологій (решітка, кільце, лінійка, гіперкуб, повний граф, зірка) з можливістю зміни кількості процесорів. Для сортування бульбашкою (пар-непарними перестановками) автоматично застосовується спеціальна «зміїна» нумерація для коректної візуалізації.
- **Анімація передачі повідомлень:** Візуалізація руху повідомлень між процесорами у реальному часі з можливістю паузи, покрокового перегляду та зміни швидкості.
- **Математична модель:** Розрахунок часу виконання, прискорення та ефективності для кожного алгоритму.
- **Графіки продуктивності:** Побудова графіків залежності часу, прискорення та ефективності від кількості процесорів.
- **Кроссплатформенність:** Код написаний на Python з використанням `tkinter` та `matplotlib`, що забезпечує роботу на Windows та Linux (з певними налаштуваннями середовища).

- Флойда-Воршелла — *Решітка*

**Множення матриці на вектор:**
- Горизонтальне розбиття — *Гіперкуб*

## 📐 Математична модель

Час виконання паралельного алгоритму розраховується за моделлю:

$$T_p = T_{calc} + T_{comm} = W(n) \cdot \tau + K \left(\alpha + \frac{w \cdot m}{\beta}\right)$$

де:
*   $T_{calc}$ – час розрахунку;
*   $T_{comm}$ – час комунікації;
*   $W(n)$ – загальна кількість операцій;
*   $p$ – кількість процесорів;
*   $n$ – розмірність задачі (кількість елементів, рівнянь, вершин, тощо);
*   $K$ – кількість комунікаційних актів, що відбуваються послідовно;
*   $\alpha$ – затримка;
*   $m$ – розмір повідомлення в елементах;
*   $w$ – розмір елемента в байтах;
*   $\beta$ – пропускна здатність;
*   $\tau$ - уніфікована змінна часу виконання однієї базової операції.

На основі цієї формули також розраховуються:

**Прискорення:** 
$$S_p = \frac{T_1}{T_p}$$

**Ефективність:** 
$$E_p = \frac{S_p}{p}$$

де $T_1$ - час виконання послідовного алгоритму.

## 📦 Збірка виконуваного файлу (.exe)

Зібраний файл `ParallelVisualizer.exe` є повністю автономним. Для його запуску на комп'ютері користувача не потрібно встановлювати Python, `tkinter`, `matplotlib` чи будь-які інші бібліотеки. Усі необхідні компоненти вже вбудовані всередині виконуваного файлу. 

Зібраний `.exe` працює на Windows. Для Linux потрібно збирати окремо на відповідній системі.
